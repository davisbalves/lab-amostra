# Laboratório de Amostragem e Inferência — v4

Aplicativo Shiny didático com três painéis: métodos de amostragem, tamanho amostral e intervalo de confiança.

Nesta versão:
- Painel 2 mostra também o número de hipertensos na amostra;
- Painel 2 calcula o erro amostral médio absoluto das estimativas acumuladas;
- Painel 3 posiciona os controles de repetição imediatamente acima do gráfico de 100 intervalos;
- Inclui a identidade visual do LAMEQ e caixa de autoria responsiva.

Execute `app.R` no RStudio/Posit com os pacotes `shiny` e `ggplot2` instalados.
